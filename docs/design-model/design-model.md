# 设计模式

## 三大类型
- 创建型模式（5种）：教怎么"造对象"
- 结构型模式（7种）：教怎么"搭架子"
- 行为型模式（11种）：教怎么"协调对象之间的关系"

## 创建型设计模式
把"造对象"这件事隐藏起来，这类设计模式要解决什么问题？
写代码时到处都要new对象，有一天要改初始化方式时，结果发现要改几十处地方！
创建型模式就是帮忙把"造对象"的逻辑集中起来，使用的人不用关心怎么造，只管用就行

总览
| 设计模式|说明 |典型场景|
|--|--|--|
|单例|全局只有一个实例|日志器、唯一外设|
|工厂方法|子类决定造哪个|不同型号的传感器驱动|
|抽象工厂|造一整套“产品族”|跨平台BSP|
|建造者|分步骤造复杂对象|协议报文组装|
|原型|克隆已有对象|模板复用|
